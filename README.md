Mumbai vs Tirupati Rainfall Analysis

Project Overview

This project compares historical rainfall data for Mumbai and Tirupati using Python and Pandas. The goal is to clean the datasets, analyze rainfall patterns, visualize the results, and identify key differences between the two cities.

Dataset

- Mumbai Rainfall Dataset
- Tirupati Rainfall Dataset
- Daily rainfall records with date and precipitation information

Project Workflow

1. Loaded both rainfall datasets.
2. Explored the data using Pandas.
3. Cleaned the datasets by fixing missing values and date formats.
4. Created new columns such as Year and Month.
5. Compared rainfall statistics between Mumbai and Tirupati.
6. Created charts to visualize rainfall patterns.
7. Summarized the findings.

Data Cleaning

- Checked for missing values.
- Converted the "time" column to datetime format.
- Saved the cleaned dataset.

Data Analysis

- Compared total rainfall.
- Compared average daily rainfall.
- Compared maximum daily rainfall.
- Compared monthly rainfall.

Visualizations

- Maximum rainfall comparison from each city 
- Average Monthly Rainfall Comparison (Line Chart)

Key Insights

1. Mumbai received more total rainfall than Tirupati.
2. Mumbai had a higher average daily rainfall.
3. The highest single-day rainfall was recorded in Mumbai.
4. Both cities received the highest rainfall during the monsoon season.
5. Tirupati experienced fewer rainy days than Mumbai.
6. Rainfall patterns differed significantly between the two cities.

Conclusion

The analysis shows that Mumbai generally experiences heavier and more frequent rainfall than Tirupati. The comparison highlights the climatic differences between the two cities and demonstrates how Pandas can be used for data cleaning and analysis.
